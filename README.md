# Enterpret — pilots

1 working pilot built for Enterpret.

### Taxonomy drift monitor

Seven taxonomy changes in 24 months, found by comparing groupings rather than labels \u2014 and \u201cData & import\u201d reads as a 43% jump in month 13 when the restated series shows it actually fell.

`companies/enterpret/enterpret-taxonomy-drift/`

## Running it

```bash
npm install
npm run dev
```

## Note on the data

Every figure in these pilots is synthetic and labelled as such in the interface.
Nothing here is connected to Enterpret's systems, and no number should be
read as a measurement of their business.
